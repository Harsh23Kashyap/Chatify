# Paperworks Help: reconstructed functional example

This is a new reconstruction from the surviving fictional handbook and manually reviewed answer/domain instructions. It is not the recovered original generated workspace, original PDF, or original video.

## Run

Import this ZIP through Chatify Load and share Nerds, or extract and run `chatify run app.yaml`. Connect your own model in Configuration. The sample uses gpt-4o-mini with a 500-token answer limit. No key is included.

Use Add documents to upload `sample-input/paperworks-handbook.pdf`. Uploads are deliberately not carried inside a portable workspace's private storage. There are no configured Markdown or external sources, so the PDF is the only evidence you add. The PDF is newly rendered from the recovered original fictional text. `sample-input/paperworks-handbook.md` is supplied only for comparison, not as a configured source.

## What was tested

The manual reconstruction was reviewed, validated and explicitly saved through the app builder, then Use this app opened a separate local workspace. The PDF was uploaded again there. This separate child was subsequently restarted with the personal model key supplied privately to its runtime. No fresh AI generation of this workspace is claimed.

Three real questions were tested with the uploaded PDF: damage reporting, changes after proof approval, and a request to guarantee tomorrow's delivery. The final damage answer cited each sentence and preserved the seven-calendar-day window; changes were individually reviewed without a promise to stop production; the delivery question returned no evidence. Four claims across the two supported answers passed the existing claim checker in this one run. This is bounded sample qualification, not a general guarantee of answer quality.

The first damage answer missed a sentence citation and correctly displayed a warning. A manual, sample-specific citation-placement clarification was then added to the recovered answer instructions. The original domain classifier instructions were restored to the question-check stage. The final three-question run used this reviewed prompt change. No product code, checker or test assertion was weakened.

Keys, conversations, uploads, account data, logs and provenance records are excluded. All policies and business names are fictional. No real orders, refunds, replacements or delivery commitments can be made here.

A complete matching narrated video has not been delivered. Current recording assets are reconstruction work, not the lost accepted original film.
