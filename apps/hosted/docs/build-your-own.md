# Build your own chat app

This hosted Chatify demo already has a model configured, so you do not need to set up a provider or paste an API key.

The easier path: open Configuration, choose Build with AI, and describe the app you want in plain words. AI drafts the full setup: the app name, look, sources, prompts and limits. Review the draft, edit anything you like, and save only when you are ready. Nothing changes until you confirm.

When your draft looks right, download it as YAML or ZIP from the same dialog. That file is your app. To run it as your own website, install Chatify from PyPI (uvx --from chatify-app chatify start) or deploy the GitHub repository to a host, then load your YAML or ZIP. Your keys and documents stay with you; they are never part of this demo.

Manual configuration is still available on the same page for advanced tweaks: model connection, sources, prompts, appearance, budget and access.
