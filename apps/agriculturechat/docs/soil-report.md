# University of Minnesota Extension: soil test interpretation

Regional guidance: Minnesota, United States. Checked31October2026. Do not transfer regional rates to other farms.

The number associated with any nutrient on a soil test report is an index value associated with one of the five relative levels.

- It is not the amount of a nutrient that is available for crop use.
- It is not the total amount of a nutrient present in the soil.
- The number listed is an index value only, and when combined with an expected yield, can be used to develop a fertilizer guideline.
