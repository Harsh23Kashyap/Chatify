# Chatify component research matrix
Original component/demo observations: 27 October 2026. License reconciliation: 31 October 2026. This records the depth actually reached, not a claim that every demo or catalog interaction was tested.

The application is static vanilla JavaScript served by Python, so adopting React/Tailwind registries wholesale would add a framework and build migration without improving the core task. Use the verified interaction patterns below as small native adaptations. Keep the existing provider, build, source, and save semantics.

## Category comparison
Buttons: Arc quiet responsive variants over Aceternity timed demo behavior. Navigation/tabs: Board underline over HeroUI pill and Bencho/Reverse/Magic docks. Forms: audiocn explicit value/label over adding audio engine. Activity/AI workflow: BeautifulUI status and approval hierarchy over shader decoration. Disclosure: Motion Primitives small purposeful reveal, native semantics retained. Cards/alerts: metadata-first OpensourceUI and Tailgrids patterns, no wholesale grid. Charts, tables, command menus and onboarding are not added without an actual workflow need. Existing orbit loader, dialogs, source drawer, model selects, reading controls and onboarding remain.

## Limits and next evidence
All 15 sites visited and own source material read. This does not mean all their components were exercised. Installation/docs/source routes were evaluated, not installed as experiments. No purchase, paid agent/MCP invocation, model call, dependency install or framework change. Exact new product changes and test/build evidence follow implementation, not this checkpoint.

## October 31 reconciliation
First-party public pages for all 15 references were read again, plus current repositories for termcn, audiocn, 23rd, HeroUI, MagicUI and Motion Primitives. This is a policy/source reconciliation, not a repeat all-demo visual audit. Bencho free blocks are MIT, Pro separately licensed; third-party photos/fonts are not included rights. Transitions allows acquired snippets in unlimited products, but not repackaging the collection; its CLI MIT license is not the snippet license. Tailgrids prohibits source redistribution and website-builder/UI-generator use. Chatify includes a builder, so this is a material reason not to copy those components. Reverse pricing permits commercial end products but does not resolve every free-item redistribution right. No premium purchase, MCP service, library installation or vendor-source copy was made for this reconciliation.
