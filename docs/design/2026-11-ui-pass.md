# November UI pass

Baseline: cd34328. Preserve the approved vermilion/sand shell, custom app themes,
public read-only boundary, saved-state semantics and answer validation.
Design inputs: elayadesign/ai-design-skills at 456d9e0 and
Appllama/appllama-skills at dd5caae. The former's linked existing-project audit
was read too. These are design references, not installed global rules.
Their conflicting font, palette, icon and native-stack prescriptions are not
applied literally. Shared principles used: hierarchy, bounded motion, semantic
colors, full state cycles, targeted diffs and inspect/fix/reinspect.

Verification is browser-based for this web app, not native simulator validation.
No paid reference-screen service was connected. Browser fixture screenshots do
not prove production answer quality or native-device frame rate.

## Iteration ledger

1. Welcome, short desktop: found 1, fixed 1. Four starter choices were below
   the work area's edge at 1280x720. Reduced the document scene and compacted
   spacing only at short desktop heights. All four starters and chat tools
   now fit in both themes without reducing 44px targets. Baseline and result:
   design-before-welcome-1280-{light,dark}.png / design-r1-welcome-1280-*.png.

2. Temporary mode: found 2, fixed 2. Oversized art hid the explanation and
   return action; the legacy serif title and tiny caption disagreed with the
   shell. Compact art, 12px caption, shared heading, 44px return action.
   Inspected 1280x720 light and 390x844 dark; explanation and return action fit.
   Evidence: design-r2-temporary-{1280-light,390-dark}.png.

3. Composer focus: found 1, fixed 1. Shared keyboard focus styling put a
   second rectangle around the textarea inside the already-highlighted input
   box. Kept one visible boundary on the containing composer. Inspected light
   desktop and dark mobile; composer lifecycle/keyboard/targets and bounded
   welcome-motion regressions pass. Evidence: design-r3-temporary-*.png.

4. Sources: found 2, fixed 2. At 1100px, the open evidence pane made the
   title zero-width and overflowed its toolbar (522px content in 476px).
   Controls now wrap below the retained title (476px content in 476px),
   preserving every action. Sources heading now uses the shared type system.
   Inspected dark 1100x720. Source-panel motion runtime and citation selected,
   close-focus, missing-excerpt, normal/reduced-motion contracts pass.
   Evidence: design-r4-{before,after}-sources-1100-*.png.

5. History empty states: found 1, fixed 1. Bare placeholder prose lacked a
   contextual state treatment. Added two quiet custom SVG compositions for
   empty conversations and no search matches, preserving exact recovery text.
   Inspected dark desktop. History refresh/retry/stale responses/search/delete
   and Undo restoration regressions pass at 320 and 1280px.
   Evidence: design-r5-welcome-1280-dark.png.

6. Configuration theme continuity: found 1, fixed 1. The dark baseline
   unexpectedly rendered light: Configuration never restored the shell's
   selected theme. Added prepaint light/dark/auto initialization without
   changing the independent app-preview theme. Inspected desktop/mobile dark.
   Delayed theme-init and shared navigation/theme geometry regressions pass.
   Evidence: design-before-settings-*-dark.png / design-r6-settings-*-dark.png.

7. Build with AI entry: found 2, fixed 2. Repeated refinement prose crowded
   the idea field, and its paid-request disclosure floated above the field,
   away from the action it explains. The guide now asks for job/sources/users;
   the unchanged cost/does-not-apply disclosure sits beside Make it better.
   Short desktop textarea spacing is compact without limiting typed growth.
   Inspected desktop dark and mobile light. Builder scope/call separation
   regression and all 8 refinement unit tests pass. Evidence: design-r7-*.

8. Saved drafts/review: found 2, fixed 2. Source-choice checkboxes and library
   retry labels retained the old green interaction color; library empty/error
   states had no visual context. Applied the shell action tokens and custom
   folder/document SVGs, leaving semantic success indicators alone. Inspected
   review desktop and narrow library error. Draft loading, pending edit locks,
   failures preserving YAML, cancel/close/backward step retention, modal tab
   loop, retry/single-flight and reduced-motion contracts pass.
   Evidence: design-r8-before-*.png / cc28-draft-status-1280.png and
   cc29-library-error-320-no-preference.png after this iteration.

9. Overlays/forms: found 3, fixed 3. Upload/profile backdrops retained a
   green tint, dialog headings used a second serif voice, and the profile
   boundary explanation was undersized. One warm neutral material, shared
   20px dialog headings, 14px profile explanation. Opened reading, upload,
   source scope, profile and actions in both themes at 390 and 1280px.
   Inspected dark mobile profile and light desktop upload after changes.
   Reading persistence/close-focus, note action confirmation, scope busy/error/
   recovery/keyboard selection and unsent-text retention regressions pass.
   Evidence: design-r9-before-*.png / design-r9-after-*.png.

10. SVG motion and final state matrix: found 1, fixed 1. Recovered document
    and temporary scenes were static despite the new animation request.
    Added one-shot SVG state introductions to documents, temporary scope,
    history and library context. Normal motion is 350-450ms, no idle loops;
    reduced/calm/none stops motion. Captured mobile/desktop flow recordings
    and inspected samples. New 8-combination theme/viewport/motion contract
    passes; original hero and 60 custom-theme palette/answer cases pass.
    Recordings are 25fps evidence, not a 60fps performance claim. Frame review
    found further first-paint and dark-library contrast issues, tracked below.

11. Recording follow-up: found 2, fixed 2. The warm hosted identity was
    applied only after the config request, briefly exposing the old green
    theme. It is now identified from server-rendered app identity and embedded
    theme before paint, reusing the same predicate at runtime and preserving
    custom/generated themes. Dark library action now owns its surface as well
    as its text color. Re-recorded and inspected desktop flow and mobile
    library state. No green flash in inspected frame samples; first-paint
    regression passes in its original fixture. New hosted-layout regression
    has its own hosted fixture, not a changed original fixture contract.

12. CI compatibility follow-up: found 1, fixed 1. The new history art was
    rendered on custom/generated app themes too, violating their surviving
    text-only history contract. Scoped art to Chatify's shell identity. Original
    320/1280 normal/reduced history contract passes without assertion changes;
    hosted 8-combination SVG/layout contract still passes.

13. Configuration startup: found 2, fixed 2. Startup decoration dismissed before
    navigation and panels settled, exposing several intermediate layouts. It now
    waits for real initial success/failure with a bounded missing-script escape.
    Initial failure previously left its recovery message below hidden panels;
    an above-fold error and explicit Reload action now remain visible. Held
    response, success and failure coverage added to the hosted design test.
    Inspected re-recorded desktop flow and success/failure pixels. Original
    12-way navigation/loading/guide and delayed-theme-init contracts pass.

14. Appearance selection: found 1, fixed 1. Shape/background shortcuts kept a
    hard-coded green selected outline inside the warm shell. Both use the shell
    action token now; app-preview colors remain independent. Actual selected
    controls inspected and asserted against the token, not a guessed RGB.

15. Narrow deep links: found 1, fixed 1. Opening a manual section at 390px
    could restore the scroll past that section into its preview. Panel alignment
    now also recovers offscreen narrow sections and runs on initial deep links.
    Original focus-visibility and preview-node/scroll-continuity contracts pass.
