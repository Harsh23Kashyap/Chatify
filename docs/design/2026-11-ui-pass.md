## Iteration ledger

1. Welcome, short desktop: found 1, fixed 1. Four starter choices were below
   the work area's edge at 1280x720. Reduced the document scene and compacted
   spacing only at short desktop heights. All four starters and chat tools
   now fit in both themes without reducing 44px targets. Baseline and result:
   design-before-welcome-1280-{light,dark}.png / design-r1-welcome-1280-*.png.

2. Temporary mode: found 2, fixed 2. Oversized art hid the explanation and
   return action; the legacy serif title and tiny caption disagreed with the
   shell. Compact art, 12px caption, shared heading, 44px return action.
   Inspected 1280x720 light and 390x844 dark; explanation and return action fit.
   Evidence: design-r2-temporary-{1280-light,390-dark}.png.

3. Composer focus: found 1, fixed 1. Shared keyboard focus styling put a
   second rectangle around the textarea inside the already-highlighted input
   box. Kept one visible boundary on the containing composer. Inspected light
   desktop and dark mobile; composer lifecycle/keyboard/targets and bounded
   welcome-motion regressions pass. Evidence: design-r3-temporary-*.png.

4. Sources: found 2, fixed 2. At 1100px, the open evidence pane made the
   title zero-width and overflowed its toolbar (522px content in 476px).
   Controls now wrap below the retained title (476px content in 476px),
   preserving every action. Sources heading now uses the shared type system.
   Inspected dark 1100x720. Source-panel motion runtime and citation selected,
   close-focus, missing-excerpt, normal/reduced-motion contracts pass.
   Evidence: design-r4-{before,after}-sources-1100-*.png.

5. History empty states: found 1, fixed 1. Bare placeholder prose lacked a
   contextual state treatment. Added two quiet custom SVG compositions for
   empty conversations and no search matches, preserving exact recovery text.
   Inspected dark desktop. History refresh/retry/stale responses/search/delete
   and Undo restoration regressions pass at 320 and 1280px.
   Evidence: design-r5-welcome-1280-dark.png.

6. Configuration theme continuity: found 1, fixed 1. The dark baseline
   unexpectedly rendered light: Configuration never restored the shell's
   selected theme. Added prepaint light/dark/auto initialization without
   changing the independent app-preview theme. Inspected desktop/mobile dark.
   Delayed theme-init and shared navigation/theme geometry regressions pass.
   Evidence: design-before-settings-*-dark.png / design-r6-settings-*-dark.png.

7. Build with AI entry: found 2, fixed 2. Repeated refinement prose crowded
   the idea field, and its paid-request disclosure floated above the field,
   away from the action it explains. The guide now asks for job/sources/users;
   the unchanged cost/does-not-apply disclosure sits beside Make it better.
   Short desktop textarea spacing is compact without limiting typed growth.
   Inspected desktop dark and mobile light. Builder scope/call separation
   regression and all 8 refinement unit tests pass. Evidence: design-r7-*.
