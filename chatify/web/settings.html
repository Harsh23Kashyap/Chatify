Document freshnessKeep local evidence up to date
Local folders are checked when someone asks a question, at most once every 30 seconds by default. Changed, added and removed documents update the search index. No background polling or model calls. Set refresh_interval in the local source YAML to change the interval.
⚙
BudgetLimit public chat usage
Daily limits reset at midnight UTC and survive restarts. 0 means no quota. Model-call limits cover answer-pipeline calls, including follow-ups and provider fallback as one invocation. Failed attempts count. Build with AI, Ask AI and deployment-plan calls count too. Provider-side retries may incur additional usage.

One submitted chat question can use several model calls for searches, the answer, checks and follow-ups. Question limits apply to the whole app or one user as labelled; the model-call limit is shared by the app. 0 means no daily limit. Usage resets at midnight UTC.

No verified provider billing meter is available. Leave Dollar cap blank for no local dollar cap. Any cap, including 0, blocks non-Demo model calls covered by this guardrail; use provider-side billing limits too.

Dollar accounting is not available yet. Setting any dollar cap blocks non-Demo answer-pipeline calls rather than guessing a bill. It does not limit owner-run configuration tests, external search fees or embedding costs. When a daily quota is reached, covered requests stop until midnight UTC or the owner changes the limit. Saving takes effect immediately; no restart is needed. Set provider-side billing limits before publishing.
