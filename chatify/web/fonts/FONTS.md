Bundled fonts (SIL Open Font License 1.1 - see OFL.txt in this directory):

- Noto Sans Regular / Bold (notosans v42, fonts.google.com)
- Noto Sans Devanagari Regular / Bold (notosansdevanagari v30)
- Noto Sans Symbols Regular (notosans symbols, arrows etc.)
- Noto Sans Symbols 2 Regular (checkmarks, misc symbols)
- Noto Sans Math Regular (math operators U+2200 block: infinity, integral,
  nabla, set membership, inequalities, sum/product; license in
  NotoSansMath-OFL.txt)

Used only by the answer-PDF export (chatify/exports.py) so ordinary Unicode
answer text, including Hindi and typographic symbols, exports as itself.
OFL 1.1 permits bundling with the application; the fonts are not sold or
redistributed standalone, and the license text ships beside them.
