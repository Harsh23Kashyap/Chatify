Step 6 of 6

Publish your app

Chatify cannot deploy for you - no cloud account is connected. You get a ready package and a checklist, and each step happens in your own accounts.

1 · Readiness check

Checks the app saved on this server: model, credentials, sources and audience notes. Local configuration checks only - live services are not contacted.

2 · Download the deployment package

A zip with your app file, theme, prompts, a Render blueprint (render.yaml), a publishing guide and a list of the environment variables to set. No keys, accounts or chat history are included.

3 · Follow the guide

PrepareUnzip, run chatify run app.yaml locally once, set the variables from SECRETS.md.
GitHubCommit every file to a new private repository in your own account.
RenderNew → Blueprint → connect the repo. Paste the secret values when Render asks. Deploy.
Check the live appOpen the Render URL, ask one real question, confirm the citations and the look.
Your own domainLast, and optional: point a domain you already own at the working Render URL in the service’s Custom Domains settings.

Render and model providers bill you directly - check their current prices. Render’s free services sleep when idle, so the first request after a quiet period can take a minute. The full guide is PUBLISHING.md inside the package.
